# Non-large families by symplectic family

The large-family source is omitted. Assignment to a symplectic family is
determined by the linear-conjugacy class of the determinant-one strict lift.
Literal containment is then tested by exact matrix membership, without a
coordinate change.

There are 101 smooth non-large input families and seven unresolved input
families. After the equal-dimensional saturation calculation, 80 smooth
families survive. Of these, 51 already contain the corresponding standard
symplectic lift literally, while 29 require a coordinate change.

For every literally aligned family of index greater than one, a single extension element was found. Thus its present linear group is generated by the standard symplectic lift and one element.
