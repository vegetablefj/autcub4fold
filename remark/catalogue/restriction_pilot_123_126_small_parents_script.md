# No. 123 and No. 126: small-parent restriction pilot

`restriction_pilot_123_126_small_parents.jl` considers the C6 actions of No. 123 inside the saved No. 95 action and of No. 126 inside the saved No. 50 action. It reads the numbered table, strict linear-containment audit, and independently computed primitive-cohomology characters before assigning any candidate.

For either parent, let (N) be its symplectic kernel and (f) the saved extra generator. The quotient generated by (fN) has order (q=12) for No. 95 and (q=3) for No. 50. A target C6 subgroup whose image has order three has a unique order-six generator in the coset (Nf^{q/3}). The script tests every (nf^{q/3}) with (n\in N), partitions the surviving subgroups under conjugation by the full parent, and compares each exact rank-22 trace histogram with the geometric character of the numbered family. This is an exhaustive search *within the selected saved parent action*; a character match alone is not a lattice or root check.

The No. 95 record already stores its S3 generators on the primitive lattice. For No. 50, the independently saved No. 51 record supplies generators of the common stable Q8 action on (S). The two primitive extensions use different ambient quadratic-space presentations, so their full rank-22 matrices cannot be identified merely by a rational basis change. Instead, the script restricts the No. 51 generators to (S_{51}), requires its Gram matrix to agree exactly with (S_{50}), checks that each restricted isometry acts trivially on the discriminant group, and extends it by the identity on (T_{50}) into the actual No. 50 primitive lattice. It then checks integrality, the Q8 element orders, the fixed-lattice rank, and the full group ID `[24,3]`.

Run `preflight`, `groups`, `lattices`, then `verify` in that order. Each stage refuses to overwrite an existing result. The groups stage writes `restriction_pilot_123_126.groups.mrdi`. Its completed run found one parent-conjugacy class with the exact geometric character for each numbered family: three raw order-six generators in No. 95 form the class for No. 123, while four in No. 50 form the class for No. 126.

The separate `lattices` stage computes the embedded (S,T,P,K), full-rank (T)-action, quotient order, and period dimension, then saves and reloads `restriction_pilot_123_126.lattices.mrdi`. The `verify` stage independently reconstructs each surviving restriction, checks that the extracted subgroup is C6 and that the root obstruction is absent, compares its Gram and action data with the earlier stage, and saves and reloads `restriction_pilot_123_126.verified.mrdi`. Both stages completed successfully. No. 123 has rank(S)=8, rank(T)=14, rank(P)=14, rank(K)=8, index 3 and dimension 6; No. 126 has rank(S)=8, rank(T)=14, rank(P)=10, rank(K)=12, index 3 and dimension 4. Each has exactly one matching parent-conjugacy class. This does not compute a new (O(S)) or claim a fresh symplectic-saturation theorem. The staged script does not edit the catalogue; its verified output can be imported separately.
