# Nos. 109, 112 and 114 in the saved No. 41 action

The frozen family table gives No. 41 as `[126,7]`, with symplectic kernel
`F_21` of order 21 and quotient order 6. Nos. 109, 112 and 114 each have
symplectic kernel `C3` (coinvariant rank 12), with respectively:

| Family | Abstract group | Quotient order | Dimension | Direct strict GL(6) edge |
| ---: | --- | ---: | ---: | --- |
| 109 | `[6,2]` | 2 | 4 | `109 -> 41`, `A_strict` |
| 112 | `[9,2]` | 3 | 2 | `112 -> 41`, `A_strict` |
| 114 | `[18,5]` | 6 | 1 | `114 -> 41`, `A_strict` |

`restriction_109_112_114_geometric_characters.g` first checks the frozen
linear groups, their common scalar subgroup of order three and each saved
conjugating matrix for the direct strict inclusion. It calculates the exact
projective primitive-H4 character from six-dimensional eigenvalue
multiplicities, checks scalar-lift independence, and writes the four-column
character TSV only after all three calculations succeed. It refuses to
overwrite an existing TSV.

`restriction_109_112_114_from_41.jl` uses the saved full No. 41 lattice-action
cache.
Its 21 kernel elements and six quotient cosets give 126 distinct rank-22
matrices. The script checks the normal-form multiplication against those
matrices and confirms the full parent group ID using a regular permutation
representation.

For a target quotient of order `q`, put `e = 6/q`. Every subgroup `B` with
`B ∩ F_21 = A ≅ C3` and quotient `Cq` contains a lift of the chosen quotient
generator in the coset `F_21 f^e`. Conversely, `B` is generated by `A` and
such a lift. The script tries every order-three `A` in `F_21` and all 21
lifts in that coset, then uses exact multiplication-table closure to retain
subgroups with the required order, kernel and quotient. It checks the
SmallGroup ID, removes duplicates and computes conjugacy orbits under the
full 126-element parent. This does not assume that one fixed lift or one
fixed `C3` captures every class.

The `groups` stage records every abstract-type parent class and its full
primitive character, marking exact geometric character matches. The
`lattices` stage processes every matching class, obtaining embedded
`S,T,P,K`, the order of the action on `T`, signatures and period dimension.
The `verify` stage closes the subgroup again, rechecks its ID and character,
reconstructs the lattice data and tests roots in `K`. It records obstructed
classes separately and retains root-free classes. Every output is saved and
reloaded, checks its inputs, and refuses to overwrite a
previous result.

Run from `remark/catalogue`, in order:

```text
GAP:   Read("restriction_109_112_114_geometric_characters.g");
Julia: restriction_109_112_114_from_41.jl preflight
Julia: restriction_109_112_114_from_41.jl groups
Julia: restriction_109_112_114_from_41.jl lattices
Julia: restriction_109_112_114_from_41.jl verify
```

For a smaller lattice smoke test, `lattices` accepts a separate output path,
the groups path, and `109:class`, `112:class` or `114:class`.
